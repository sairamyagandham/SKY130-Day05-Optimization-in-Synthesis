# Day 5 – Optimization in Synthesis | SKY130 RTL Design and Synthesis Workshop

## Overview
This repository documents my Day 5 learning and practical experiments from the **RTL Design and Synthesis Workshop using SKY130** conducted by VLSI System Design (VSD).

The main focus of Day 5 was understanding how different Verilog coding styles affect synthesis results and how synthesis tools optimize RTL designs.

## Topics Covered

### 1. If-Case Constructs
- Understanding `if` and `case` statements.
- Synthesis of conditional statements.
- Understanding how coding styles affect hardware implementation.

### 2. Incomplete and Overlapping Cases
- Understanding incomplete case statements.
- Studying overlapping case conditions.
- Identifying latch inference due to incomplete assignments.
- Observing synthesis results for different case structures.

### 3. For Loops and Generate Statements
- Understanding `for` loops in Verilog.
- Learning the use of `generate` and `genvar`.
- Implementing repetitive hardware structures.
- Comparing generated hardware structures through synthesis.

## Practical Experiments
- RTL coding and simulation of conditional logic.
- Synthesis of different `if` and `case` constructs.
- Experiments with incomplete and overlapping case statements.
- Analysis of latch inference.
- Implementation of designs using `for` loops.
- Implementation of hardware using `generate` statements.
- Observing synthesized logic using Yosys.
- Examining gate-level schematics and synthesis statistics.

## Tools Used
- Verilog HDL
- Yosys
- SKY130 Standard Cell Library
- Icarus Verilog
- GTKWave
- Ubuntu Linux

## Key Learnings
- Different Verilog coding styles can produce different hardware structures.
- Incomplete assignments in combinational logic can infer latches.
- Case statements must be written carefully to avoid unintended hardware.
- Generate statements help create repetitive hardware structures.
- Synthesis optimization converts RTL descriptions into efficient hardware implementations.
